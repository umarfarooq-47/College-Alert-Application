# College Alert Application

### 🚀 Project Overview
An intuitive, mobile-first student notification portal built for **Hazara University** to help busy students plan their schedules and stay informed about crucial campus events, examinations, and official holidays.

### 💼 Internship Details
* **Company:** Arch Technologies
* **Domain:** Android App Development Internship
* **Timeline:** Month 1 - Task 1
* **Developer:** Umar Farooq

### ✨ Key Features
- **Hazara University Student Portal Header:** Custom university branding.
- **Dynamic Category Filters:** Instantly sort alerts by *Exams*, *Events*, *Academic Alerts*, and *Holidays*.
- **Live Notification Badge:** Real-time visual cue for unread notifications.
- **Clean Grid Layout:** Minimal, responsive card design optimized perfectly for mobile screens.

### 🛠️ Tech Stack Used
- HTML5 / CSS3 (Tailwind CSS)
- Vanilla JavaScript (DOM Manipulation & State Management)
